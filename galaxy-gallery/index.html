This one needs a server ✦

The galaxy is built with ES modules, and browsers refuse to load those from a file:// page — opened by double-click it can only ever be a black screen.

From the project folder, run:

npx http-server -p 8080 -c-1

then open http://localhost:8080/galaxy-gallery/
